# Proxmox Ceph HCI on Scaleway

Deploy a hyperconverged Proxmox + Ceph cluster on Scaleway Elastic Metal using **Terraform** + **Ansible**.

## Quick Start

### 1. Prerequisites

```bash
# Install tools
pip install ansible jmespath netaddr
brew install terraform  # or apt install terraform

# Install Ansible roles
cd ansible
ansible-galaxy install -r requirements.yml
```

### 2. Deploy Infrastructure (Terraform)

```bash
cd terraform
cp terraform.tfvars.example terraform.tfvars
vim terraform.tfvars  # Configure ssh_key_ids, service_password

terraform init
terraform apply

# Wait ~15 min for servers to install
scw baremetal server list zone=fr-par-2
```

### 3. Configure Cluster (Ansible)

```bash
cd ../ansible

# Step 1: Bootstrap nodes (SSH, network, /etc/hosts)
ansible-playbook playbooks/01-bootstrap.yml

# Step 2: Create Proxmox cluster
ansible-playbook playbooks/02-cluster.yml

# Step 3: Setup Ceph storage
ansible-playbook playbooks/03-ceph.yml

# Or all at once:
ansible-playbook playbooks/site.yml
```

## Workflow Comparison

### Old Workflow (Manual Scripts)
```
terraform apply → Wait → Manual script per node → Manual cluster creation → Manual Ceph
```

### New Workflow (Ansible)
```
terraform apply → Wait → ansible-playbook site.yml → Done!
```
