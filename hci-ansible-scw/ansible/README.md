# Ansible - Proxmox Ceph HCI Configuration

Automate Proxmox cluster + Ceph setup using Ansible instead of manual scripts.

## Architecture

```
ansible/
├── ansible.cfg              # Ansible configuration
├── requirements.yml         # Role dependencies
├── inventory/
│   ├── hosts.yml           # Inventory (generated by Terraform)
│   └── group_vars/
│       └── proxmox.yml     # Cluster configuration
├── playbooks/
│   ├── 01-bootstrap.yml    # Initial node setup (SSH, hosts, network)
│   ├── 02-cluster.yml      # Proxmox cluster creation
│   └── 03-ceph.yml         # Ceph storage setup
└── files/                   # SSL certs, etc.
```

## Prerequisites

```bash
# Install Ansible
pip install ansible jmespath netaddr

# Install required roles
ansible-galaxy install -r requirements.yml
```

## Usage

### 1. After Terraform Deploy

Terraform generates the inventory automatically at `inventory/hosts.yml`.

### 2. Bootstrap Nodes

```bash
# Configure SSH, /etc/hosts, network interfaces
ansible-playbook playbooks/01-bootstrap.yml
```

### 3. Create Proxmox Cluster

```bash
# Initialize cluster on pve1, join pve2/pve3
ansible-playbook playbooks/02-cluster.yml
```

### 4. Setup Ceph Storage

```bash
# Install Ceph, create OSDs, pools
ansible-playbook playbooks/03-ceph.yml
```

### All-in-One

```bash
ansible-playbook playbooks/site.yml
```

## Key Variables

| Variable | Description |
|----------|-------------|
| `pve_cluster_enabled` | Enable clustering |
| `pve_cluster_clustername` | Cluster name |
| `pve_ceph_enabled` | Enable Ceph setup |
| `pve_ceph_network` | Ceph public network |
| `pve_ceph_cluster_network` | Ceph replication network |
| `pve_ceph_osds` | List of OSD disks |

## Advantages over Manual Scripts

1. **Idempotent** - Run multiple times safely
2. **Declarative** - Define desired state, not steps
3. **Tested** - `lae.proxmox` role is battle-tested
4. **Ceph support** - Built-in Ceph configuration
5. **Reproducible** - Same result every time
